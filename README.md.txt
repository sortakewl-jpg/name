# KH1 Sora in Dark Souls: Remastered

A mashup project that brings Kingdom Hearts 1–style Sora into Dark Souls: Remastered.  
This includes KH1 movement, KH1 combo timing, KH1 Cure, and the KH1 Kingdom Key.

## What this project does
- Replaces the player character with KH1 Sora
- Adds KH1 movement (run, jump, dodge roll)
- Adds KH1 3-hit combo with accurate timing
- Adds KH1 Cure (40–50% heal)
- Adds KH1 Kingdom Key weapon
- Tunes Hollow Soldiers for KH-style pacing

## Required games
- **Dark Souls: Remastered (Steam)** — host game
- **KINGDOM HEARTS HD 1.5+2.5 ReMIX (Steam)** — asset source
